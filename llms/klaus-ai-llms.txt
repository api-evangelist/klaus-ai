# Klaus AI

> Klaus is a managed cloud hosting platform for OpenClaw AI agents, operated by Usebits Inc (Y Combinator W26, San Francisco). It provisions an isolated, pre-configured OpenClaw instance on dedicated AWS ARM compute in about five minutes, wired to messaging channels, Google Workspace, browser automation, email, scheduled tasks, semantic memory, and inbound webhooks. Model access is brokered through OpenRouter with bring-your-own-key and ChatGPT-subscription options.

Generated by the API Evangelist enrichment pipeline on 2026-07-19. Klaus publishes no llms.txt of its own (/llms.txt returns the single-page-application shell), so this file was generated from the API Evangelist catalog entry and the artifacts in this repository. Klaus publishes no OpenAPI description; the API surface described here was read from the provider's own published npm client, @klausai/cli.

## APIs

- [Klaus Platform API](https://klausai.com/faq/): tRPC API at https://api.klausai.com managing hosted OpenClaw instances, agents, integrations, models, and chat sessions, plus an OpenAI-compatible chat-completions proxy at /openclaw/v1/chat/completions.

## Authentication

- [Authentication profile](authentication/klaus-ai-authentication.yml): API key in the `x-api-key` header (created at https://klausai.com/account, or the `KLAUS_API_KEY` environment variable), or a bearer session token from the OAuth 2.0 Device Authorization Grant (RFC 8628) at `/api/auth/device/code` and `/api/auth/device/token`. The `x-klaus-instance-id` header selects the target instance.
